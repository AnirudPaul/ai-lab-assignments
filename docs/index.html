Experiments

Experiment 1 — Graph traversal from scratch

Depth-First & Breadth-First Search

Recursive and iterative DFS, BFS with a queue, frontier tracing, and a measured comparison of search-tree shape, shortest-path optimality and peak memory.

frontier growth space comparison traversal trees
Experiment 2 — Informed search and admissible heuristics

8-Puzzle Solver with A*

A* with four heuristics (uniform cost, misplaced tiles, Manhattan, Manhattan + linear conflict), verifying that all return the same optimal path while differing by ~100x in nodes expanded.

heuristic comparison scaling solution path
Experiment 3 — Evolutionary search

Travelling Salesman by Genetic Algorithm

Order crossover, inversion mutation and tournament selection on a 25-city tour of India, benchmarked honestly against nearest-neighbour and 2-opt local search.

convergence robustness tour evolution tours
Experiment 4 — First-order rule induction

FOIL on a Family Tree

A real FOIL implementation - sequential covering driven by information gain - inducing grandfather, grandmother, sibling and uncle from ground facts, plus beam search and post-pruning to fix where greedy search fails.

family tree gain trace rule quality
Experiment 5 — Forward chaining with certainty factors

Expert System

A 20-rule diagnostic knowledge base with MYCIN-style certainty factors, negated conditions, and how/why explanation of every conclusion.

expert system
Experiment 6 — Handwritten digit recognition

MLP on MNIST

A PyTorch multilayer perceptron reaching 98.2%, with a controlled test showing a parameter-identical network without activations collapses to 91%.

Experiment 7 — Eigenfaces + support vector machine

SVM Face Recognition on LFW

PCA eigenfaces feeding an RBF SVM, tuned by grid search, evaluated with balanced accuracy against the majority-class baseline rather than chance.

ablation components eigenfaces grid search results samples
Experiment 8 — Unsupervised clustering

K-Means on MNIST

Lloyd's algorithm with k-means++ written from scratch, and an honest account of which digits clustering recovers and which it does not.

Experiment 9 — Convolutional image classification

CNN on CIFAR-10

A BatchNorm CNN with GPU-side augmentation reaching 86.9%, against a fully connected network given 4.7x more parameters that reaches only 54.7%.
